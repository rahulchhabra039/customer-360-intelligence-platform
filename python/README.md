# Python Analysis

This folder contains the Python analysis completed for the Customer 360 project.

## Analysis completed

- GA4 e-commerce funnel analysis
- Conversion and drop-off calculations
- Mobile-versus-desktop checkout comparison
- Two-proportion z-test
- 95% confidence interval
- Business recommendations

## Main findings

- 61,252 users viewed a product.
- 12,545 users added a product to their cart.
- 9,715 users began checkout.
- 4,419 users completed a purchase.
- The largest drop-off occurred between product view and add to cart.
- Mobile checkout conversion was 46.17%, compared with 44.95% for desktop.
- The device difference was not statistically significant (p = 0.2403).

This was an observational analysis, not a live randomised A/B test. The results identify patterns but do not prove causation.
